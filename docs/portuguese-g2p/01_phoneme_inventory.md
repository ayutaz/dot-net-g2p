# ポルトガル語 IPA音素インベントリ

## 1. 概要

ポルトガル語はロマンス諸語の中でも最も豊富な母音体系を持つ言語の一つであり、口母音・鼻母音・二重母音・三重母音を有する。子音体系は比較的保守的で、中世ガリシア=ポルトガル語の7摩擦音体系が現代では4摩擦音に縮約されている。

ブラジルポルトガル語(BP)とヨーロッパポルトガル語(EP)で音素インベントリに差異があり、特に母音体系と異音規則で大きく異なる。

---

## 2. 口母音 (Oral Vowels)

### 2.1 共通音素 (BP/EP共通、強勢位置)

| IPA  | 調音位置                | 例語        |
|------|------------------------|------------|
| /a/  | 開母音（中舌寄り）       | p**a**rto  |
| /ɛ/  | 前舌半広母音            | caf**é**   |
| /e/  | 前舌半狭母音            | p**e**ga   |
| /i/  | 前舌狭母音              | l**i**nha  |
| /ɔ/  | 後舌半広母音            | av**ó**    |
| /o/  | 後舌半狭母音            | p**o**der  |
| /u/  | 後舌狭母音              | f**u**i    |

### 2.2 BP/EP共通の追加口母音

| IPA  | 調音位置                | 説明                                    |
|------|------------------------|-----------------------------------------|
| /ɐ/  | 中舌ほぼ開母音          | 強勢位置で鼻子音前に出現（BP/EP共通）。非強勢位置で/a/の弱化先 |

Barbosa & Albano (2004, JIPA) に基づき、/ɐ/ はBP/EP共通の音素として扱う。BPでも /a/ と /ɐ/ は強勢位置で対立する（例: cama [ˈkɐmɐ] vs cata [ˈkata]）。

### 2.3 ヨーロッパポルトガル語固有音素

| IPA  | 調音位置                | 説明                                    |
|------|------------------------|-----------------------------------------|
| /ɨ/  | 中舌ほぼ狭母音          | EP固有。非強勢eの弱化先。BPには存在しない |

**EPの口母音合計: 9音素** (/a, ɛ, e, i, ɔ, o, u, ɐ, ɨ/)
**BPの口母音合計: 8音素** (/a, ɛ, e, i, ɔ, o, u, ɐ/) — Barbosa & Albano (2004) に準拠

### 2.4 非強勢位置での母音弱化

**EP**: /a, ɛ, e, ɔ, o/ → [ɐ, ɨ, ɨ, u, u] に弱化（語末ではさらに極端）
**BP**: /a, ɛ, e, ɔ, o/ → [ɐ, i, i, u, u] に弱化（語末非強勢位置）

## 3. 鼻母音 (Nasal Vowels)

BP/EP共通で5つの鼻母音音素を持つ。ポルトガル語の顕著な特徴であり、フランス語と並んでロマンス諸語で鼻母音を体系的に保持する言語。

| IPA  | 調音位置                | 例語            | 正書法の表記            |
|------|------------------------|----------------|------------------------|
| /ɐ̃/  | 中舌鼻母音              | m**ã**e, c**an**to | ã, an, am          |
| /ẽ/  | 前舌半狭鼻母音          | v**en**to      | en, em                 |
| /ĩ/  | 前舌狭鼻母音            | c**in**to      | in, im                 |
| /õ/  | 後舌半狭鼻母音          | c**on**ta      | on, om                 |
| /ũ/  | 後舌狭鼻母音            | m**un**do      | un, um                 |

**注記**:
- 鼻母音は独立音素として扱う（V + 鼻子音の連鎖ではない）。
- /ɐ̃/ の音素表記について: 音韻論的分析によっては /ã/ を基底音素とする立場もある（Barbosa & Albano 2004）。本ドキュメントでは音声実現が [ɐ̃] であることに基づき /ɐ̃/ を採用する。enum名 `ANasal` はどちらの分析とも互換性がある。

## 6. 子音 (Consonants)

### 6.1 子音音素表 (BP/EP共通)

|            | 両唇 | 唇歯 | 歯茎 | 後部歯茎 | 硬口蓋 | 軟口蓋 |
|------------|------|------|------|---------|--------|--------|
| 破裂音(無声) | /p/  |      | /t/  |         |        | /k/    |
| 破裂音(有声) | /b/  |      | /d/  |         |        | /ɡ/    |
| 摩擦音(無声) |      | /f/  | /s/  | /ʃ/     |        |        |
| 摩擦音(有声) |      | /v/  | /z/  | /ʒ/     |        |        |
| 鼻音       | /m/  |      | /n/  |         | /ɲ/    |        |
| 側面音     |      |      | /l/  |         | /ʎ/    |        |
| はじき音   |      |      | /ɾ/  |         |        |        |

上記に加え、口蓋垂摩擦音 /ʁ/ がロティック音素として存在する（詳細はセクション6.2を参照）。

**子音音素: 20音素** (p, b, t, d, k, ɡ, f, v, s, z, ʃ, ʒ, m, n, ɲ, l, ʎ, ɾ, ʁ)

### 6.2 R音素（ロティック）

ポルトガル語のR音素は特殊な扱いが必要:

| 音素  | 位置                     | 実現             |
|-------|--------------------------|------------------|
| /ɾ/   | 母音間（対立位置）        | [ɾ] はじき音     |
| /ʁ/   | 語頭、/l,n,s/後、母音間(rr) | 方言により多様（下記） |

**/ɾ/ と /ʁ/ は母音間でのみ対立する** (caro /ˈkaɾu/ vs carro /ˈkaʁu/)。それ以外の位置では相補分布。

**注記**: 子音表の /ʎ/ について、BPの多くの方言（特に農村部・北東部）では /ʎ/ が /j/ に合流する「イェイスモ（yeismo）」が進行中であるが、標準BPでは /ʎ/ を維持する。本実装では標準発音として /ʎ/ を出力する。

**注記**: /ɲ/ について、BPでは [j̃] + 先行母音鼻音化で実現されることがある（例: banho [ˈbɐ̃j̃u]）。enum には鼻化わたり音 `JNasal` (/j̃/) を含めており、この異音規則の出力に対応する。

**ロティックの実現形**:
- **EP**: [ʁ] 有声口蓋垂摩擦音（標準）、[ʀ] 口蓋垂ふるえ音（古い/方言）、[r] 歯茎ふるえ音（北部方言）
- **BP**: [x] 無声軟口蓋摩擦音、[χ] 無声口蓋垂摩擦音、[ʁ] 有声口蓋垂摩擦音、[h] 無声声門摩擦音（方言による多様性が極めて大きい）

## 7. 異音 (Allophones)

### 7.1 ブラジルポルトガル語(BP)固有の異音

| 音素  | 異音      | 条件                       | 例                     |
|-------|----------|---------------------------|------------------------|
| /t/   | [tʃ]     | /i/, /ĩ/ の前              | **t**ia → [ˈtʃiɐ]     |
| /d/   | [dʒ]     | /i/, /ĩ/ の前              | **d**ia → [ˈdʒiɐ]     |
| /l/   | [w]      | 音節末（l-vocalization）    | ma**l** → [ˈmaw]      |
| /ʁ/   | [x]      | 語頭・rr（方言依存）        | **r**ato → [ˈxatu]    |
| /ʁ/   | [h]      | 語頭・rr（リオ等）          | **r**ato → [ˈhatu]    |
| /ʁ/   | [χ]      | 語頭・rr（方言依存）        | ca**rr**o → [ˈkaχu]   |
| /s/   | [ʃ]      | 音節末（リオ方言等）        | me**s**mo → [ˈmeʒmu]  |
| /z/   | [ʒ]      | 有声子音前の音節末          | me**s**mo → [ˈmeʒmu]  |

**BP口蓋化**: /t/→[tʃ] と /d/→[dʒ] はBPの最も顕著な特徴。ほぼ全ブラジル方言で見られるが、南部一部・北東部一部では口蓋化しない。

**BP l-vocalization**: 音節末 /l/ → [w] はBP標準で普遍的。EP では [ɫ]（暗いl）になる。

### 7.2 ヨーロッパポルトガル語(EP)固有の異音

| 音素  | 異音      | 条件                        | 例                     |
|-------|----------|-----------------------------|------------------------|
| /l/   | [ɫ]      | 音節末（dark l）             | ma**l** → [ˈmaɫ]      |
| /l/   | [ɬ]      | 語末（一部方言、側面摩擦音）  |                        |
| /ɾ/   | [ɾ̥]      | 語末（無声化）               | amo**r** → [ɐˈmoɾ̥]    |
| /e/   | [ɨ]      | 非強勢位置（極度の弱化）      | m**e**nino → [mɨˈninu] |
| /a/   | [ɐ]      | 非強勢位置                   | c**a**sa → [ˈkazɐ]    |
| /s/   | [ʃ]      | 音節末（全方言）             | pa**s**ta → [ˈpaʃtɐ]  |
| /z/   | [ʒ]      | 有声子音前の音節末            | me**s**mo → [ˈmeʒmu]  |

### 7.3 共通の異音

| 音素  | 異音      | 条件                        |
|-------|-----------|-----------------------------|
| /n/   | [ŋ]      | 軟口蓋子音前                 |
| /n/   | [ɱ]      | 唇歯子音前                   |
| /n/   | [n̪]      | 歯子音前                     |

## 8. enum設計提案: PortugueseIpaPhoneme

スペイン語(28種)・フランス語(40種)の設計に倣い、ポルトガル語のenumを提案する。

### 設計方針

1. **コア音素**（BP/EP共通の音素）を中心に構成
2. **方言固有の異音**は独立enumメンバーとして追加（異音処理で使用）
3. **鼻母音**は独立音素として扱う（V+N分解ではない）
4. byte基底で255以内に収める

### 提案: PortugueseIpaPhoneme : byte (49種)

```csharp
public enum PortugueseIpaPhoneme : byte
{
    // --- 口母音 (0-8) ---
    A = 0,       // /a/ 開母音（中舌寄り）
    E = 1,       // /e/ 前舌半狭母音
    Eh = 2,      // /ɛ/ 前舌半広母音
    I = 3,       // /i/ 前舌狭母音
    O = 4,       // /o/ 後舌半狭母音
    Oh = 5,      // /ɔ/ 後舌半広母音
    U = 6,       // /u/ 後舌狭母音
    Schwa = 7,   // /ɐ/ 中舌ほぼ開母音 (EP強勢位置 + BP/EP非強勢)
    HighCentral = 8, // /ɨ/ 中舌ほぼ狭母音 (EP固有。close central unrounded vowel)

    // --- 鼻母音 (9-13) ---
    ANasal = 9,  // /ɐ̃/ 鼻母音
    ENasal = 10, // /ẽ/ 鼻母音
    INasal = 11, // /ĩ/ 鼻母音
    ONasal = 12, // /õ/ 鼻母音
    UNasal = 13, // /ũ/ 鼻母音

    // --- 半母音 (14-15) ---
    J = 14,      // /j/ 硬口蓋接近音
    W = 15,      // /w/ 軟口蓋唇接近音

    // --- 破裂音 (16-21) ---
    P = 16,      // /p/ 無声両唇破裂音
    B = 17,      // /b/ 有声両唇破裂音
    T = 18,      // /t/ 無声歯茎破裂音
    D = 19,      // /d/ 有声歯茎破裂音
    K = 20,      // /k/ 無声軟口蓋破裂音
    G = 21,      // /ɡ/ 有声軟口蓋破裂音

    // --- 摩擦音 (22-27) ---
    F = 22,      // /f/ 無声唇歯摩擦音
    V = 23,      // /v/ 有声唇歯摩擦音
    S = 24,      // /s/ 無声歯茎摩擦音
    Z = 25,      // /z/ 有声歯茎摩擦音
    Sh = 26,     // /ʃ/ 無声後部歯茎摩擦音
    Zh = 27,     // /ʒ/ 有声後部歯茎摩擦音

    // --- 鼻音 (28-30) ---
    M = 28,      // /m/ 両唇鼻音
    N = 29,      // /n/ 歯茎鼻音
    Ny = 30,     // /ɲ/ 硬口蓋鼻音

    // --- 側面音 (31-32) ---
    L = 31,      // /l/ 歯茎側面接近音
    Lh = 32,     // /ʎ/ 硬口蓋側面接近音

    // --- ロティック (33-34) ---
    R = 33,      // /ɾ/ 歯茎はじき音
    Rr = 34,     // /ʁ/ 有声口蓋垂摩擦音 (強いR)

    // --- BP固有異音 (35-38) ---
    Ch = 35,     // /tʃ/ 無声後部歯茎破擦音 (BP: /t/+/i/)
    Jh = 36,     // /dʒ/ 有声後部歯茎破擦音 (BP: /d/+/i/)
    X = 37,      // /x/ 無声軟口蓋摩擦音 (BP: /ʁ/の実現形)
    H = 38,      // /h/ 無声声門摩擦音 (BP: /ʁ/の実現形)

    // --- EP固有異音 (39-40) ---
    DarkL = 39,  // /ɫ/ 軟口蓋化側面音 (EP: 音節末/l/)
    Rh = 40,     // /χ/ 無声口蓋垂摩擦音 (/ʁ/の異音。フランス語enumのRh命名に準拠)

    // --- 共通異音 (41-43) ---
    Ng = 41,     // /ŋ/ 軟口蓋鼻音 (/n/の異音: 軟口蓋子音前)
    NLabiodental = 42, // /ɱ/ 唇歯鼻音 (/n/の異音: 唇歯子音前)
    NDental = 43, // /n̪/ 歯鼻音 (/n/の異音: 歯子音前)

    // --- 弱化異音 (44-46) ---
    Beta = 44,   // /β/ 有声両唇摩擦音 (/b/の弱化異音、EP向け)
    Dh = 45,     // /ð/ 有声歯摩擦音 (/d/の弱化異音、EP向け)
    Gh = 46,     // /ɣ/ 有声軟口蓋摩擦音 (/ɡ/の弱化異音、EP向け)

    // --- 鼻わたり音 (47-48) ---
    JNasal = 47, // /j̃/ 鼻化わたり音 (鼻二重母音の要素: ẽj̃, ũj̃ 等)
    WNasal = 48, // /w̃/ 鼻化わたり音 (鼻二重母音の要素: ɐ̃w̃, õw̃ 等)
}
```

### enum設計の補足

**合計: 49種** (口母音9 + 鼻母音5 + 半母音2 + 破裂音6 + 摩擦音6 + 鼻音3 + 側面音2 + ロティック2 + BP異音4 + EP異音2 + 共通異音3 + 弱化異音3 + 鼻わたり音2)

**他言語enumとの比較**:
| 言語 | enum数 | 構成 |
|------|--------|------|
| スペイン語 | 35種 | 母音5+半母音2+子音19+異音9 |
| フランス語 | 40種 | 口母音12+鼻母音4+半母音3+子音17+異音4 |
| ポルトガル語 | 49種 | 口母音9+鼻母音5+半母音2+子音20+異音13 |

**ポルトガル語が多い理由**:
- 鼻母音5種が独立音素（フランス語と同様だがEP固有母音/ɨ/が追加）
- BP/EP間の異音差が大きい（口蓋化破擦音、l-vocalization、ロティック多様性）
- ロティックの実現形が方言で極めて多様
- 弱化異音(β,ð,ɣ)と鼻わたり音2種(j̃,w̃)が必要
- 05_allophone_rules.md の `PortugueseAllophoneFeatures` は9フラグのため `ushort` 基底（byte では不足）

## 9. 方言(Dialect) enum設計

```csharp
public enum PortugueseDialect : byte
{
    /// <summary>ブラジルポルトガル語（サンパウロ/リオ標準）</summary>
    Brazilian = 0,

    /// <summary>ヨーロッパポルトガル語（リスボン標準）</summary>
    European = 1,
}
```

### 方言間の主要な音素レベル差異

| 特徴 | BP (Brazilian) | EP (European) |
|------|---------------|---------------|
| 母音インベントリ | 8口母音 (/ɐ/ 含む) | 9口母音 (/ɨ/ 追加) |
| 母音弱化 | 軽度 | 極度（/ɨ/まで弱化） |
| /t/ + /i/ | [tʃ] (口蓋化) | [t] (無変化) |
| /d/ + /i/ | [dʒ] (口蓋化) | [d] (無変化) |
| 音節末 /l/ | [w] (母音化) | [ɫ] (暗いl) |
| 音節末 /s/ | [s] (大部分) / [ʃ] (リオ) | [ʃ] (全方言) |
| 強いR /ʁ/ | [x, χ, h, ʁ] (多様) | [ʁ, ʀ, r] |
