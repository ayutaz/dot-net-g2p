# ポルトガル語の音節構造とストレス規則

## 1. 音節構造概要

ポルトガル語のネイティブ語彙における最大音節構造は **CCVVCC** である（核に二重母音 VV を認める場合。単母音核のみを核と見なす文献では CCVCC とするものもある）。外来語では語頭3子音（例: stress の借用 → epenthesis で解消）や語末3子音（CVCCC: perspicaz の一部解釈）が出現する場合があるが、ネイティブ語彙の範囲では CCVVCC を上限とする。大多数の音節は開音節（母音で終わる）であり、コーパスでの分布は以下の通り:

| 音節型 | 比率 |
|--------|------|
| CV     | 60%  |
| CVC    | 15%  |
| V      |  8%  |
| CCV    |  5%  |
| VC     |  4%  |
| その他 |  8%  |

## 2. Onset（頭子音）

### 2.1 単子音 onset

全ての単子音が onset 位置に立てる:

/p, b, t, d, k, g, f, v, s, z, ʃ, ʒ, m, n, ɲ, l, ʎ, ɾ, ʁ/

### 2.2 子音クラスタ onset

ポルトガル語のネイティブ子音クラスタは **閉鎖音/摩擦音 + 流音（/ɾ/ or /l/）** の組み合わせに限定される:

| + /ɾ/ | + /l/ |
|--------|-------|
| /pɾ/ (prato) | /pl/ (plano) |
| /bɾ/ (braço) | /bl/ (bloco) |
| /tɾ/ (três)  | /tl/ (**不可**: スペイン語と異なりネイティブでは不許容) |
| /dɾ/ (dragão) | /dl/ (**不可**) |
| /kɾ/ (cravo) | /kl/ (classe) |
| /gɾ/ (grande) | /gl/ (globo) |
| /fɾ/ (frio)  | /fl/ (flor) |
| /vɾ/ (livro中) **語中のみ（語頭不可）** | /vl/ (**語彙的に未証例**: ネイティブ語にほぼ存在しない) |

**スペイン語との相違点:**
- スペイン語では /tl/ がメキシコ方言で onset クラスタとして許容される（Nahuatl 借用語: Tlaxcala等）
- ポルトガル語では /tl/, /dl/ は onset クラスタとして不許容。これは同器官性（homorganicity）の制約に起因する — 歯/歯茎閉鎖音と歯/歯茎側面音の組み合わせが排除される
- 両言語とも基本的な obstruent + liquid パターンは共通

### 2.3 外来語の onset クラスタ

外来語・学術語では追加のクラスタが出現する:
- /ps/ (psicologia)
- /pn/ (pneumático) - BP では /p/ が脱落し /n/ のみ
- /gn/ (gnomo)
- /mn/ (mnemónico)

これらは正書法上存在するが、発話では通常先頭子音が脱落するか、BP では母音挿入（epenthesis）で解消される。

## 3. Nucleus（核母音）

### 3.1 単母音核

全ての口母音・鼻母音が核になれる:

**口母音:** /a, ɐ, ɛ, e, i, ɔ, o, u/ (EP追加: /ɨ/)
**鼻母音:** /ɐ̃, ẽ, ĩ, õ, ũ/

### 3.2 二重母音（Diphthongs）

#### 下降二重母音（Falling diphthongs） - 主要なタイプ

下降二重母音は **母音 + 半母音** の順序で、同一音節内に収まる:

**口二重母音:**

| 正書法 | IPA | 例 |
|--------|-----|----|
| ai, ái | /aj/ | pai, cai |
| au, áu | /aw/ | mau, pau |
| ei, êi | /ej/ | lei, sei |
| éi     | /ɛj/ | idéia (旧正書法) |
| eu, êu | /ew/ | meu, seu |
| éu     | /ɛw/ | céu, chapéu |
| iu     | /iw/ | viu, partiu |
| oi, ôi | /oj/ | boi, coisa |
| ói     | /ɔj/ | herói, dói |
| ou     | /ow/ → BP: /o/ | ouro, pouco |
| ui     | /uj/ | fui, cuidado |

**鼻二重母音:**

| 正書法 | IPA | 例 |
|--------|-----|----|
| ão, am | /ɐ̃w̃/ | não, pão, falam |
| ãe, ãi | /ɐ̃j̃/ | mãe, cães, pães |
| õe     | /õj̃/ | canções, botões |
| em, en | /ẽj̃/ | bem, vem, também |
| ui (muito) | /ũj̃/ | muito およびその屈折/派生形（muita, muitos, muitas, muitíssimo 等） |

**注意:** BP では /ou/ → /o/ の単母音化が実質的に完了しており、ほぼ全ての話者で /o/ として実現する。

**注意:** 鼻二重母音 /ũj̃/ は正書法上、鼻母音化を明示する記号（ã/õ や語末 m/n）を持たない特殊なケースである。先行子音 /m/ の鼻音性が後続母音に波及する音声学的メカニズムによって鼻母音化が生じる。

#### 上昇二重母音（Rising diphthongs）

上昇二重母音は **半母音 + 母音** の順序で、解釈が分かれる:

| パターン | 例 | 解釈 |
|----------|----|------|
| /ja/ ia  | farmácia | 二重母音 or 分離母音（方言依存） |
| /je/ ie  | espécie | 二重母音 or 分離母音 |
| /jo/ io  | ginásio | 二重母音 or 分離母音 |
| /wa/ ua  | água | 二重母音 or 分離母音 |
| /we/ ue  | frequente | 二重母音 |
| /wo/ uo  | contínuo | 二重母音 or 分離母音 |
| /wi/ ui  | cuidado | 下降二重母音 /uj/ と解釈されることも |

**重要:** ポルトガル語では上昇二重母音と分離母音（hiatus）の区別が曖昧で、方言や話速により変動する。スペイン語と比べてこの区別が体系的でない点が実装上の課題となる。

### 3.3 三重母音（Triphthongs）

三重母音は **半母音 + 母音 + 半母音** の構成で、主に /g/ と /k/（正書法 g, qu）の後に現れる:

**口三重母音:**

| 正書法 | IPA | 例 |
|--------|-----|----|
| uai    | /waj/ | Paraguai, Uruguai |
| uei    | /wej/ | averiguei |
| uou    | /wow/ | averiguou |

**鼻三重母音:**

| 正書法 | IPA | 例 |
|--------|-----|----|
| uão    | /wɐ̃w̃/ | saguão |
| uõe    | /wõj̃/ | saguões |

### 3.4 分離母音（Hiatus）

二つの母音が別々の音節に属する場合:

**分離母音の条件:**
1. 強母音（a, e, o）+ 強母音: po.e.ta, ca.os, co.e.lho
2. アクセント付き弱母音 + 他の母音: sa.í.da, ba.ú, re.ú.ne
3. 同一母音の連続: co.or.de.nar, re.es.tru.tu.rar

**二重母音 vs 分離母音の判別アルゴリズム（実装向け）:**
```
if 隣接する2母音:
  if 強母音 + 強母音 → 分離母音（hiatus）
  if アクセント記号付き í, ú → 分離母音（hiatus）
    // SpanishOrthography.CanFormDiphthong と同様のロジック
  if 弱母音(i,u) + 強母音(a,e,o) → 上昇二重母音（デフォルト動作）
    // 上昇二重母音の曖昧性: 方言や話速で分離母音になるケースがある。
    // デフォルトは二重母音として扱い、例外は辞書で対処する方針を推奨。
    // SpanishSyllabifier では CanFormDiphthong が弱+強で true を返す。
  if 強母音 + 弱母音(i,u) → 下降二重母音
  if 弱母音 + 弱母音 → 二重母音（通常）
```

## 4. Coda（末尾子音）

### 4.1 単子音 coda

ポルトガル語の coda は非常に制限的で、以下の4つの弁別的位置のみ:

| 音素 | 表記例 | 備考 |
|------|--------|------|
| /S/ (sibilant) | pas.ta, paz | EP: /ʃ/, BP: /s/ or /ʃ/（方言依存） |
| /ɾ/ or /ʁ/ | par.te, mar | EP: /ɾ/, BP: /ʁ/ or /h/ |
| /l/ or /w/ | al.to, sal | EP: /ɫ/ (暗いL), BP: /w/ (母音化) |
| /N/ (nasal) | can.ta | 音韻論的には coda /N/ だが、音声的には先行母音の鼻母音化として実現し、独立した子音セグメントとしては現れない |

### 4.2 複合 coda

2子音からなる複合 coda は非常に稀で、常に最終要素が歯擦音:
- /ɾS/: perspicaz → [pɨɾʃ.pi.kaʃ] (EP)
- /lS/: solstício → [sol.ʃti.sju] (EP)
- /NS/: transporte → [tɾɐ̃ʃ.pɔɾ.tɨ] (EP)

### 4.3 BP での coda 制約

BP では coda の閉鎖音が許容されない。外来語の語末閉鎖音には母音挿入が起こる:
- adapt → a.da.pi.tar（ではなく a.dap.tar ではない場合がある）
- técnico → [ˈtɛk.ni.ku] or [ˈtɛ.ki.ni.ku]

## 5. Onset Maximization

音節境界の決定には **Onset Maximization**（最大頭子音原則）を適用する。2つの母音間の子音列を、可能な限り後続音節の onset に割り当てる:

**アルゴリズム:**
```
V.C₁C₂V の場合:
  if C₁C₂ が有効な onset クラスタ → V.C₁C₂V（両方 onset）
  else → VC₁.C₂V（C₁ は coda、C₂ は onset）

V.C₁C₂C₃V の場合:
  if C₂C₃ が有効な onset → VC₁.C₂C₃V
  else → VC₁C₂.C₃V
  // 注: ネイティブ語彙では3子音 onset は存在しない（最大2子音: obstruent + liquid）。
  // 外来語の場合は epenthesis が適用されるため、正書法ベースの音節分割では
  // 3子音 onset のケースを考慮する必要はない。
```

**例:**
- a.brir → /a.ˈbɾiɾ/ (/bɾ/ は有効な onset)
- ins.tru.men.to → /ĩʃ.tɾu.ˈmẽ.tu/ (/tɾ/ は有効な onset, /ʃ/ は coda)
- abs.tra.to → /abʃ.ˈtɾa.tu/ (EP) or /a.biʃ.ˈtɾa.tu/ (BP with epenthesis)

## 6. ストレス規則

### 6.1 統計的分布

| ストレスパターン | 名称 | 比率 | 例 |
|------------------|------|------|-----|
| 後ろから2番目 | paroxítona（paroxytone） | 74% | momento, peludo |
| 最終音節 | oxítona（oxytone） | 23% | falar, café |
| 後ろから3番目 | proparoxítona（proparoxytone） | 3% | máquina, último |

### 6.2 デフォルトストレス位置（アクセント記号なし）

**統一的ルール:** 語末から -s, -ns, -m を除去した後、a/e/o で終わるなら paroxytone、それ以外は oxytone。以下は具体的な語末パターンへの展開:

#### Paroxytone（次末音節強勢）がデフォルトとなる語末パターン:
- **-a(s)**: bonita, bonitas
- **-e(s)**: gente, gentes
- **-o(s)**: bonito, bonitos
- **-am**: viveram, falaram
- **-em**: dizem, homem
- **-ens**: jovens, origens

#### Oxytone（最終音節強勢）がデフォルトとなる語末パターン:
- **-r**: falar, viver, dormir
- **-l**: animal, papel, azul
- **-z**: rapaz, feliz, capuz
- **-i, -u**: compreendi, comi, peru, menu
- **-is, -iz, -us, -uz**: anis, aprendiz, Jesus, avestruz
- **-im, -ins**: jardim, jardins
- **下降二重母音** (-ai, -au, -ei, -eu, -iu, -ou, -ui): samurai, bacalhau, Europeu
- **鼻二重母音** (-ão, -ões): opinião, canções

**注意: 上昇二重母音の曖昧性:** `-ia`, `-ie`, `-io`, `-ua`, `-ue`, `-uo` で終わる語は上昇二重母音と分離母音（hiatus）の解釈が曖昧であり、paroxytone になるケースが多い（例: alegria, farmácia）。正書法上 -a で終わるため上記の paroxytone ルールに該当するが、二重母音/分離母音の判定が音節数に影響する点に注意が必要。

### 6.3 アクセント記号によるストレス明示

#### 鋭アクセント（acento agudo: á, é, í, ó, ú）
- 開母音を示す: café /ka.ˈfɛ/, avó /a.ˈvɔ/
- デフォルトでない位置にストレスがあることを示す

#### 曲折アクセント（acento circunflexo: â, ê, ô）
- 閉母音を示す: você /vo.ˈse/, avô /a.ˈvo/
- 鋭アクセントと同じストレス規則に従うが、母音の質が異なる

#### チルダ（til: ã, õ）
- 鼻母音を示す: irmã /iɾ.ˈmɐ̃/, canção /kɐ̃.ˈsɐ̃w̃/
- **重要:** チルダは通常ストレスも示すが、後末音節にある場合はストレスを示さない
  - 例: órfão → ストレスは ó にあり、ã ではない

#### グレーブアクセント（acento grave: à）
- ストレスを示さない。前置詞 a + 冠詞 a の融合（crase）のみに使用

### 6.4 ストレス判定アルゴリズム（実装向け）

```
function GetStressedSyllable(word, syllables):
  // Phase 1: 鋭/曲折アクセント（最優先）
  // á, é, í, ó, ú, â, ê, ô が存在すれば、その音節がストレス位置
  for each syllable in syllables:
    for each char in syllable:
      if char in {á, é, í, ó, ú, â, ê, ô}:
        return syllable_index

  // Phase 2: チルダ（鋭/曲折アクセントが存在しない場合のみ到達）
  // Phase 1 で見つからなかった = 鋭/曲折アクセントが語内に存在しない
  // この場合、ã/õ がストレスを示す（例: irmã, canção）
  // 鋭/曲折アクセントが存在する場合は Phase 1 で返っているため、
  // órfão のようなケースでは ó（Phase 1）が返り、ã は無視される
  for each syllable in syllables:
    for each char in syllable:
      if char in {ã, õ}:
        return syllable_index

  // Phase 3: デフォルトストレス（アクセント記号なし）
  if syllables.count == 1:
    return 0

  lastChar = word の最後の文字（小文字化）
  // Paroxytone がデフォルトの語末パターン
  // 統一的ルール: 語末から -s, -ns, -m を除去した後、a/e/o で終わるなら paroxytone
  if word ends with vowel(a,e,o) or vowel+s or -am or -em or -ens:
    return syllables.count - 2  // 次末音節

  // それ以外は Oxytone
  return syllables.count - 1  // 最終音節
```

### 6.5 Proparoxytone（前々末音節強勢）

- 全ての proparoxytone 語は **必ずアクセント記号を持つ**
- アルゴリズムの Phase 1 で自動的に検出される
- 例: máquina, penúltimo, diabólico, atómico, médico

### 6.6 接語（Clitics）のストレス

ポルトガル語の接語は統語的に独立だが、音韻的にはホスト語に依存する:

- **前接語（proclitic）**: 動詞の前（否定文等）: não **me** diga
- **後接語（enclitic）**: 動詞の後（肯定文）: diga-**me**
- **中間接語（mesoclitic）**: 動詞語幹と活用語尾の間（未来形/条件形）: dir-**me**-á

接語は独立したストレスを持たず、ホスト語のストレスパターンに影響を与えない（例: falar-me のストレスは falar と同じく -lar にある）。G2P実装ではハイフン接続の接語を適切に分離し、ストレス計算から除外する必要がある。

**接語代名詞のリスト:** me, te, se, o, a, os, as, lhe, lhes, nos, vos, lo, la, los, las, no, na, nos, nas

**中間接語（mesoclitic）の分離アルゴリズム:**
```
function SeparateMesoclitic(word):
  // dir-me-á → 動詞語幹 "dir" + 接語 "me" + 活用語尾 "á"
  parts = word.split('-')
  if parts.count >= 3:
    for i in 1..parts.count-2:
      if parts[i] in clitic_pronouns:
        // 動詞語幹 + 活用語尾を再結合してストレス計算
        verb_form = parts[0] + parts[last]  // "dir" + "á" → "dirá"
        return (verb_form, clitics: parts[1..last-1])
  // 後接語の場合: diga-me → "diga" + "me"
  if parts.count >= 2 AND parts[last] in clitic_pronouns:
    return (parts[0], clitics: [parts[last]])
  return (word, clitics: [])
```

## 7. SpanishSyllabifier/StressAssigner との類似点・相違点

### 7.1 音節分割の比較

| 側面 | スペイン語 (SpanishSyllabifier) | ポルトガル語（提案） |
|------|-------------------------------|---------------------|
| **アプローチ** | 正書法ベース | 正書法ベース（同様） |
| **Onset maximization** | 適用あり | 適用あり（同様） |
| **有効な onset クラスタ** | bl,br,cl,cr,dr,fl,fr,gl,gr,pl,pr,tr,tl + ch,ll,rr,qu,gu,gü | bl,br,cl,cr,dr,fl,fr,gl,gr,pl,pr,tr + ch,lh,nh,rr,qu,gu,gü |
| **/tl/ onset** | 許容（特にメキシコ方言） | 不許容 |
| **ダイグラフ onset** | ch, ll, rr, qu, gu, gü | ch, lh, nh, rr, qu, gu, gü（旧正書法対応） |
| **母音分類** | 強母音(a,e,o) / 弱母音(i,u) | 同様だが母音体系が複雑 |
| **二重母音判定** | 強+弱 or 弱+強 → 二重母音 | 同様だが上昇二重母音の扱いが曖昧 |
| **三重母音** | 弱+強+弱 | 同様（w+V+j パターン） |
| **分離母音** | 強+強、アクセント付き í/ú | 同様 + 同一母音連続 |
| **サイレント u** | qu+e/i, gu+e/i | qu+e/i, gu+e/i（同様） |
| **Coda 制約** | 比較的制限的（/s, n, ɾ, l, d, θ/ 等）だが英語より限定的 | 非常に制限的（/S,ɾ,l,N/ のみ） |

### 7.2 ストレス判定の比較

| 側面 | スペイン語 (StressAssigner) | ポルトガル語（提案） |
|------|---------------------------|---------------------|
| **アクセント記号** | á, é, í, ó, ú | á, é, í, ó, ú, â, ê, ô, ã, õ |
| **デフォルト paroxytone** | 母音, -n, -s で終わる語（y 末尾は除外: 子音扱いで oxytone） | -a(s), -e(s), -o(s), -am, -em, -ens で終わる語 |
| **デフォルト oxytone** | 上記以外 | -r, -l, -z, -i, -u, -is, -iz, -us, -uz, -im, -ins, 下降二重母音 |
| **y 末尾** | 子音扱い（oxytone） | N/A（ポルトガル語では y は外来語のみ） |
| **チルダのストレス機能** | N/A | あり（ただし唯一のアクセントの場合のみ） |
| **曲折アクセント** | N/A | あり（閉母音のストレス） |
| **Proparoxytone** | アクセント記号で検出 | 同様（全 proparoxytone にアクセント記号あり） |
| **接語処理** | 不要（通常） | 必要（enclitic/mesoclitic のハイフン分離） |

### 7.3 実装上の推奨事項

1. **SpanishSyllabifier からの再利用可能な部分:**
   - 全体的なアルゴリズム構造（母音検索 → 核範囲決定 → coda 長計算）
   - Onset maximization のロジック
   - 二重母音/三重母音の判定フレームワーク

2. **ポルトガル語固有の変更点:**
   - `IsValidDigraphOnset`: ch, lh, nh, rr, qu, gu, gü に変更
   - `IsValidConsonantClusterOnset`: /tl/ を除外
   - `HasWrittenAccent`: â, ê, ô, ã, õ を追加
   - `CanFormDiphthong`: 上昇二重母音の曖昧さに対応する追加ロジック
   - ストレス判定: チルダの特殊処理（ã/õ のストレス判定）
   - 接語分離: ハイフン後の代名詞を分離してストレス計算

3. **FrenchSyllabifier のパターン活用:**
   - フランス語は音素ベースで音節分割を行うが、ポルトガル語では正書法ベースの方が適切
   - ただし、G2P後の音素列に対する音節分割が必要な場合はフランス語のアプローチを参考にできる
   - FrenchSyllabifier の `IsValidOnset` では2子音 onset として「obstruent + liquid（ただし TL, DL を除外）」を判定しており（FrenchSyllabifier.cs:137-143）、ポルトガル語でも同様の TL/DL 除外が必要
