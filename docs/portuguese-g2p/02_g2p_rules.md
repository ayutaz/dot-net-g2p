# ポルトガル語 G2P 変換規則（書記素→音素）

## 1. 概要

ポルトガル語の正書法→IPA音素変換はスペイン語よりも複雑で、フランス語に近い難易度を持つ。主な複雑性の要因は以下の通り:

1. **母音の開/閉の区別**: ストレス有無で母音の質が変化（e→/e/ or /ɛ/、o→/o/ or /ɔ/）
2. **母音弱化**: 非ストレス母音が大幅に弱化（特にEP）
3. **鼻母音**: フランス語同様の鼻母音体系（5つの鼻母音 + 5つの鼻二重母音）
4. **位置依存規則**: s, x, r, l が位置で大きく変化
5. **方言差**: ブラジルポルトガル語(BP)とヨーロッパポルトガル語(EP)で音韻体系が異なる

## 2. 提案するフェーズ構成

既存のスペイン語G2P（3フェーズ）とフランス語G2P（6フェーズ）を参考に、ポルトガル語には**7フェーズ**構成を提案する:

```
Phase 1: ダイグラフ・マルチグラフ認識 + 鼻母音化（最長一致、vowel + n/m/tilde を統合処理）
Phase 2: 文脈依存子音（s/z, c/g, x, r の位置依存変換）
Phase 3: 母音変換（ストレス依存の開/閉母音）
Phase 4: 半母音化（i/u + 母音 → 半母音）
Phase 5: 母音弱化（非ストレス母音の還元 — 方言依存）
Phase 6: 黙字処理（h, 語末子音等）
Phase 7: 異音処理（AllophoneProcessor: BP t/d口蓋化、EP b/d/g弱化等）
```

> **注**: 7フェーズは概念的・論理的な分割であり、実装上は1パスの統合走査で処理する。フランス語実装（`GraphemeToPhonemeRules.ConvertGraphemes`）も名目上6フェーズだが実際には統合的な走査で処理しており、ポルトガル語でも同様のアプローチを取る。

> **注**: ストレス位置の決定は Phase 1 の前に行う（書記素レベルでの音節分割 + ストレス決定）。ポルトガル語はストレス位置が母音の質（Phase 3）と母音弱化（Phase 5）に影響するため、スペイン語パターン（`StressAssigner.MarkStress(word, Syllabifier.Syllabify(word))`）を採用する。詳細はセクション 11.1 を参照。

### 2.1 フェーズ構成の根拠

| フェーズ | 根拠 |
|---------|------|
| Phase 1 | スペイン語/フランス語と同様のマルチグラフ認識（ch, lh, nh, rr, ss, gu, qu 等）に加え、鼻母音化（ã/õ/am/em/im/om/um/ão/ões 等）を統合処理。フランス語実装で `TryTwoCharMultigraph` 内に `NasalVowelizer.TryNasalize()` を統合しているパターンに準拠 |
| Phase 2 | スペイン語の c/g 軟音化に加え、s/z 交替と x の4通り発音が加わる |
| Phase 3 | スペイン語にはない「母音の質」の区別。ストレス位置で /e/~/ɛ/, /o/~/ɔ/ が変化 |
| Phase 4 | スペイン語と同様の半母音化。i/u が母音の前で /j/, /w/ に変化 |
| Phase 5 | EP固有の大幅な母音弱化。フランス語のschwa処理に相当する |
| Phase 6 | フランス語ほど複雑ではないが、h の黙字処理が必要 |
| Phase 7 | BP t/d 口蓋化、EP b/d/g 弱化等の異音規則。スペイン語/フランス語の `AllophoneProcessor` パターンに準拠 |

### 2.2 既存実装との比較

```
スペイン語（3フェーズ）:
  ダイグラフ → 文脈依存 → 単純対応

フランス語（6フェーズ）:
  マルチグラフ → 文脈依存子音 → 鼻母音化 → 半母音化 → 位置の法則 → 黙字

ポルトガル語（7フェーズ、提案）:
  ダイグラフ+鼻母音化 → 文脈依存子音 → 母音変換 → 半母音化 → 母音弱化 → 黙字 → 異音処理
```

> **注**: フランス語実装では鼻母音化が独立フェーズとして記載されているが、実装上は `TryTwoCharMultigraph` 内で `NasalVowelizer.TryNasalize()` を呼び出す統合処理になっている。ポルトガル語でも同様に Phase 1 のマルチグラフ認識に鼻母音化を統合する。これにより n/m が消費された後に文脈依存子音（Phase 2）の判定が崩れる問題を回避できる。

## 3. Phase 1: ダイグラフ・マルチグラフ認識 + 鼻母音化

### 3.1 ダイグラフ（2文字）

| 書記素 | IPA | 備考 |
|--------|-----|------|
| ch | /ʃ/ | 常に /ʃ/（スペイン語の /tʃ/ とは異なる） |
| lh | /ʎ/ | 硬口蓋側面接近音（スペイン語 ll の古い発音に相当） |
| nh | /ɲ/ | 硬口蓋鼻音（スペイン語 ñ、フランス語 gn に相当） |
| rr | /ʁ/(EP) /h/(BP) | 有声口蓋垂摩擦音(EP) / 声門摩擦音(BP)。常にふるえ音/摩擦音 |
| ss | /s/ | 母音間でも常に無声（s の有声化を防ぐ） |
| qu | /k/ (e,i前) / /kw/ (a,o前) | e/i の前では u は黙字 |
| gu | /g/ (e,i前) / /gw/ (a,o前) | e/i の前では u は黙字。gue→/ge/, gui→/gi/ |
| xc | /s/ (e,i前) | exceção など |
| sc | /s/ (e,i前) | EP: 特定の語で。BP: 一般的 |

### 3.2 頻出パターン（分解処理）

以下のパターンはトリグラフとして一括処理するのではなく、既存フェーズの組み合わせで分解処理する:

| パターン | 分解 | 結果 | 例 |
|---------|------|------|-----|
| ção | ç → /s/ (Phase 2) + ão → /ɐ̃w̃/ (Phase 1 鼻母音化) | /sɐ̃w̃/ | nação |
| ções | ç → /s/ (Phase 2) + ões → /õj̃s/ (Phase 1 鼻母音化) | /sõj̃s/ | nações |

トリグラフとして一括処理すると、例外的な文脈（語中の "ção" + 母音等）でルールの衝突が起こりうるため、分解処理を採用する。

### 3.3 鼻母音化の統合処理

Phase 1 ではダイグラフ認識と同時に鼻母音化を処理する。フランス語実装の `NasalVowelizer.TryNasalize()` パターンに準拠し、`TryTwoCharDigraph` 内で鼻母音化判定を呼び出す設計とする。鼻母音化の詳細規則はセクション 4 を参照。

### 3.4 実装方針

- スペイン語/フランス語と同様に最長一致で処理
- `TryTwoCharDigraph()`, `TryNasalize()` メソッドに分割（鼻母音化をダイグラフ認識に統合）
- qu/gu は後続母音を先読みして黙字判定
- 旧正書法テキストとの互換性のため、qu/gu + ü のケース（güe/güi → /gwe/, /gwi/）も Phase 1 で処理する（セクション 10.4 参照）

```csharp
// 実装イメージ
// ch → /ʃ/
if (c0 == 'c' && c1 == 'h')
{
    phonemes.Add(PortugueseIpaPhoneme.Sh);
    consumed = 2;
    return true;
}

// lh → /ʎ/
if (c0 == 'l' && c1 == 'h')
{
    phonemes.Add(PortugueseIpaPhoneme.Lh);
    consumed = 2;
    return true;
}

// nh → /ɲ/
if (c0 == 'n' && c1 == 'h')
{
    phonemes.Add(PortugueseIpaPhoneme.Ny);
    consumed = 2;
    return true;
}
```

## 4. 鼻母音化規則（Phase 1 に統合して処理）

> 鼻母音化は概念的には独立したフェーズだが、実装上は Phase 1（ダイグラフ・マルチグラフ認識）に統合して処理する（セクション 3.3 参照）。以下に鼻母音化の詳細規則を記載する。

### 4.1 鼻母音（単母音）

| 書記素パターン | IPA | 条件 | 例 |
|---------------|-----|------|-----|
| ã | /ɐ̃/ | 常に鼻母音 | mã (母) |
| õ | /õ/ | 常に鼻母音 | põe (置く) |
| an/am + 子音 or 語末 | /ɐ̃/ | 後続が母音でない場合 | canto /ˈkɐ̃tu/ |
| en/em + 子音 or 語末 | /ẽ/ | 後続が母音でない場合 | tempo /ˈtẽpu/ |
| in/im + 子音 or 語末 | /ĩ/ | 後続が母音でない場合 | cinco /ˈsĩku/ |
| on/om + 子音 or 語末 | /õ/ | 後続が母音でない場合 | onda /ˈõdɐ/ |
| un/um + 子音 or 語末 | /ũ/ | 後続が母音でない場合 | um /ũ/ |

### 4.2 鼻二重母音

| 書記素 | IPA | 例 |
|--------|-----|-----|
| ão | /ɐ̃w̃/ | mão (手), são (聖なる) |
| ãe / ães | /ɐ̃j̃/ | mãe (母), pães (パン複数) |
| õe / ões | /õj̃/ | põe (置く), leões (ライオン複数) |
| am (語末、動詞活用) | /ɐ̃w̃/ | falam (彼らは話す) |
| em (語末) | /ẽj̃/ | bem (良い), também (〜も) |
| ém (語末) | /ẽj̃/ | também |
| ui (muito等) | /ũj̃/ | muito (とても) |

### 4.3 鼻母音化の判定ロジック

フランス語の `NasalVowelizer` と同様のアプローチ:

```
1. 母音字 + n/m を検出
2. 後続文字を確認:
   a. 後続が母音 → 鼻母音化しない（n/m は onset として次の音節に属する）
      例: cama /ˈkɐmɐ/ (ベッド) — m + a → m は次の音節の onset
   b. 後続が同じ n/m（nn, mm） → 鼻母音化しない
      例: annas → a + nn → 非鼻母音
   c. 後続が子音 or 語末 → 鼻母音化
      例: campo /ˈkɐ̃pu/ — a + m + p → 鼻母音化
3. tilde (ã, õ) → 常に鼻母音化
```

### 4.4 実装上の注意点

- フランス語 `NasalVowelizer.TryNasalize()` のパターンを踏襲し、Phase 1 のマルチグラフ認識内で呼び出す
- ポルトガル語はフランス語よりも鼻二重母音が多い（ão, ãe, õe, am, em 等）
- 鼻二重母音は Phase 1 で一括処理（Phase 4 の半母音化より先に処理する必要がある）
- n/m を鼻母音化で消費した場合でも、その位置情報を保持し、後続の文脈依存子音（Phase 2）で正しく文脈判定できるようにする

## 5. Phase 2: 文脈依存子音

### 5.1 s の変換規則

ポルトガル語の s はスペイン語の s よりも複雑で、4通りの発音を持つ:

| 位置 | IPA (EP) | IPA (BP) | 例 |
|------|----------|----------|-----|
| 語頭 | /s/ | /s/ | sala /ˈsalɐ/ |
| 母音間 | /z/ | /z/ | casa /ˈkazɐ/ |
| 母音間 ss | /s/ | /s/ | passo /ˈpasu/ |
| 有声子音前 (coda) | /ʒ/ | /z/ (SP) or /ʒ/ (RJ) | mesmo /ˈmeʒmu/(EP), /ˈmezmu/(BP-SP), /ˈmeʒmu/(BP-RJ) |
| 無声子音前 (coda) | /ʃ/ | /s/ (SP) or /ʃ/ (RJ) | festa /ˈfɛʃtɐ/(EP), /ˈfɛstɐ/(BP-SP), /ˈfɛʃtɐ/(BP-RJ) |
| 語末 | /ʃ/ | /s/ (SP) or /ʃ/ (RJ) | mês /meʃ/(EP), /mes/(BP-SP), /meʃ/(BP-RJ) |

**実装方針**: EP と BP で coda s の処理を分岐。母音間の有声化はスペイン語にもない、ポルトガル語固有の特徴。

> **BP 方言差に関する注記**: BP の coda s/z は地域差が大きい。サンパウロ/南部方言では /s/（無声子音前）、/z/（有声子音前）を使うが、リオデジャネイロ/北東部方言では EP と同様に /ʃ/（無声子音前）、/ʒ/（有声子音前）を使う。実装では BP のデフォルト方言パラメータとして /s/, /z/（サンパウロ標準）を使い、リオ方言オプションとして /ʃ/, /ʒ/ を提供する設計を検討する。

### 5.2 c/ç の変換規則

| 書記素 | 条件 | IPA | 例 |
|--------|------|-----|-----|
| c + e/i | 前舌母音前 | /s/ | cedo /ˈsedu/ |
| c + a/o/u | 後舌母音前 | /k/ | casa /ˈkazɐ/ |
| c + 子音 | | /k/ | classe /ˈklasɨ/(EP) |
| ç | 常に | /s/ | cabeça /kɐˈbesɐ/ |
| cc + e/i | 旧正書法のみ | /s/（最初の c は黙字） | acção → ação (AO 1990) |

スペイン語と同様のパターン。ただしスペイン語のように Castilian distincion (/θ/) は存在しない。

> **正書法改定（AO 1990）に関する注記**: 本実装は AO 1990（2009年発効の正書法改定）準拠を主対象とする。改定により "acção" → "ação"、"direcção" → "direção" 等の変更が行われ、現代正書法では "cc" は基本的に出現しない。旧正書法テキストとの互換性のため、"cc + e/i" は最初の c を黙字として扱い /s/ を出力する。なお、旧正書法の "cc" を /ks/ とする記述が散見されるが、EP では最初の c は発音されず黙字である。

### 5.3 g/j の変換規則

| 書記素 | 条件 | IPA | 例 |
|--------|------|-----|-----|
| g + e/i | 前舌母音前 | /ʒ/ | gente /ˈʒẽtɨ/ |
| g + a/o/u | 後舌母音前 | /g/ | gato /ˈgatu/ |
| g + 子音 | | /g/ | grande /ˈgɾɐ̃dɨ/。EP では母音間で [ɣ] に弱化（異音規則） |
| j | 常に | /ʒ/ | janela /ʒɐˈnɛlɐ/ |

スペイン語の g+e/i→/x/ と異なり、ポルトガル語では /ʒ/（有声後部歯茎摩擦音）となる。

### 5.4 x の変換規則

ポルトガル語の x は最も不規則な文字で、4通りの発音を持つ:

| IPA | 条件/パターン | 例 |
|-----|-------------|-----|
| /ʃ/ | 語頭、子音前、多くの母音間 | xadrez /ʃɐˈdɾeʃ/, boxe /ˈbɔʃi/ |
| /z/ | ex- + 母音 | exame /iˈzɐmi/ |
| /ks/ | 一部の母音間（ラテン語由来） | taxi /ˈtaksi/, fixo /ˈfiksu/ |
| /s/ | 稀なケース（接頭辞由来） | próximo /ˈpɾɔsimu/ |

**実装方針**: x の発音は正書法だけからは決定できないケースが多いため、例外辞書への依存度が高い。基本ルールとして:
- 語頭 x → /ʃ/
- ex + 母音 → /z/
- 子音前 x → /ʃ/
- デフォルト（母音間）→ /ʃ/（最頻出）
- /ks/, /s/ のケースは例外辞書で対処

> **注**: 「母音間 x のデフォルトを /ʃ/ とする」戦略の妥当性は、ipa-dict / WikiPron のポルトガル語データで定量的に検証すべき。例外辞書のエントリ数見積もりに直結する重要な判断であり、実装時にコーパス分析で /ʃ/, /z/, /ks/, /s/ の分布を確認すること。

### 5.5 r の変換規則

| 位置 | IPA (EP) | IPA (BP) | 例 |
|------|----------|----------|-----|
| 語頭 | /ʁ/ | /h/~/x/ | rio /ˈʁiu/(EP), /ˈhiu/(BP) |
| rr（母音間） | /ʁ/ | /h/~/x/ | carro /ˈkaʁu/(EP), /ˈkahu/(BP) |
| 母音間（単独 r） | /ɾ/ | /ɾ/ | caro /ˈkaɾu/ |
| 子音クラスター内 | /ɾ/ | /ɾ/ | prato /ˈpɾatu/ |
| n/l/s の後 | /ʁ/ | /h/ | honra /ˈõʁɐ/(EP) |
| coda（語末・子音前） | /ɾ/~/ʁ/ | /h/~/ɾ/ | mar /maɾ/(EP), /mah/(BP) |

**実装方針**: r/rr のルール分離。
- 語頭、rr、n/l/s 後 → "強い R"（/ʁ/ or /h/ 方言依存）
- 母音間（単独）、クラスター内 → "弱い R"（/ɾ/ tap）
- coda → 方言依存（EP: /ɾ/ or /ʁ/, BP: /h/ or 脱落）

### 5.6 z の変換規則

| 位置 | IPA (EP) | IPA (BP) | 例 |
|------|----------|----------|-----|
| 語頭・母音間 | /z/ | /z/ | zero /ˈzɛɾu/ |
| 有声子音前 (coda) | /ʒ/ | /z/ | feliz dia → [fɨˈliʒ] |
| 無声子音前 (coda) | /ʃ/ | /s/ | luz clara → [luʃ] |
| 語末（単独） | /ʃ/ | /s/ or /ʃ/ | vez /veʃ/(EP), /ves/(BP) |

EP では s と z が coda 位置で同じ振る舞い（/ʃ/ or /ʒ/）をする。

### 5.7 その他の子音

| 書記素 | IPA | 備考 |
|--------|-----|------|
| b | /b/ | 基本形 /b/。EP では母音間で [β] に弱化（後述の異音規則参照） |
| d | /d/ | 基本形 /d/。EP では母音間で [ð] に弱化。BP: /i/ の前で /dʒ/（口蓋化、Phase 7 AllophoneProcessor で処理） |
| f | /f/ | 常に /f/ |
| k | /k/ | 外来語のみ |
| l | /l/(onset) / /ɫ/(EP coda) / /w/(BP coda) | coda で方言差大 |
| m | /m/ | onset のみ。coda では前の母音を鼻母音化（Phase 1 で処理） |
| n | /n/ | onset のみ。coda では前の母音を鼻母音化（Phase 1 で処理） |
| p | /p/ | 常に /p/ |
| t | /t/ | EP: 常に /t/。BP: /i/ の前で /tʃ/（口蓋化） |
| v | /v/ | 常に /v/ |
| w | /w/ | 外来語のみ |
| y | /j/ or /i/ | 外来語のみ |

### 5.8 EP の b/d/g 弱化（lenition）

EP（特にポルトガル北部・中部）では有声破裂音 /b/, /d/, /g/ が母音間で摩擦音に弱化する。スペイン語と同様のパターンだが、BP ではこの弱化は起こらない。

| 音素 | 弱化先 | 条件 | 例 |
|------|--------|------|-----|
| /b/ | [β] | 母音間（語頭・鼻母音後を除く） | saber [sɐˈβeɾ] |
| /d/ | [ð] | 母音間（語頭・鼻母音後を除く） | poder [puˈðeɾ] |
| /g/ | [ɣ] | 母音間（語頭・鼻母音後を除く） | lugar [luˈɣaɾ] |

**実装方針**: b/d/g 弱化は `AllophoneProcessor`（Phase 7）で処理する。スペイン語実装の `AllophoneProcessor.ApplyLenition()` パターンを踏襲し、方言パラメータ（EP のみ有効）で制御する。

## 6. Phase 3: 母音変換（ストレス依存）

> **ストレス位置決定のタイミング**: 母音変換はストレス位置に依存するため、書記素レベルでの音節分割とストレス決定を Phase 1 の前に事前処理として行う。スペイン語パターン（`StressAssigner.MarkStress(word, Syllabifier.Syllabify(word))`）を採用し、ストレス情報を全フェーズで共有する。ストレス決定のアルゴリズムはセクション 11.1 の Step 1 を参照。

### 6.1 ストレス位置での母音

| 書記素 | IPA | 条件 | 例 |
|--------|-----|------|-----|
| a / á | /a/ | ストレスあり | casa /ˈkazɐ/ |
| â | /ɐ/ | ストレスあり（閉a） | câmara /ˈkɐmɐɾɐ/ |
| e（無標） | /ɛ/ or /e/ | ストレスあり。語彙的に決定（辞書依存） | |
| é | /ɛ/ | ストレスあり（開e） | café /kɐˈfɛ/ |
| ê | /e/ | ストレスあり（閉e） | você /voˈse/ |
| i / í | /i/ | 常に | vida /ˈvidɐ/ |
| o（無標） | /ɔ/ or /o/ | ストレスあり。語彙的に決定（辞書依存） | |
| ó | /ɔ/ | ストレスあり（開o） | avó /ɐˈvɔ/ |
| ô | /o/ | ストレスあり（閉o） | avô /ɐˈvo/ |
| u / ú | /u/ | 常に | tudo /ˈtudu/ |

### 6.2 アクセント記号なしの e/o の開閉問題

ポルトガル語G2Pの最大の難題は、**アクセント記号のない ストレス母音 e と o の開閉が正書法だけでは決定できない**こと:

- **belo** (美しい) → /ˈbɛlu/（開e）
- **pelo** (毛) → /ˈpelu/（閉e）
- **avó** (祖母) → /ɐˈvɔ/（開o、アクセント記号あり）
- **avô** (祖父) → /ɐˈvo/（閉o、アクセント記号あり）
- **bolo** (ケーキ) → /ˈbolu/（閉o）
- **fogo** (火) → /ˈfogu/（閉o）
- **olho** (目) → /ˈoʎu/（閉o）

**対処方針**:
1. アクセント記号がある場合（é/ê/ó/ô）→ 確定的に変換
2. アクセント記号がない場合のデフォルトルール:
   - ストレス e → デフォルト /e/（閉e）
   - ストレス o → デフォルト /o/（閉o）
3. 例外辞書で開母音ケースを補完

## 7. Phase 4: 半母音化

### 7.1 上昇二重母音（Rising Diphthongs）

| パターン | IPA | 例 |
|---------|-----|-----|
| i + 母音 | /j/ + V | diabo /ˈdjabu/, diário /diˈaɾju/ |
| u + 母音 | /w/ + V | quadro /ˈkwadɾu/, quando /ˈkwɐ̃du/ |

### 7.2 下降二重母音（Falling Diphthongs）

| パターン | IPA | 例 |
|---------|-----|-----|
| ai | /aj/ | pai /paj/ |
| au | /aw/ | mau /maw/ |
| ei | /ej/ | lei /lej/ |
| éi | /ɛj/ | anéis /ɐˈnɛjʃ/, papéis /pɐˈpɛjʃ/ |
| eu | /ew/ | meu /mew/ |
| éu | /ɛw/ | véu /vɛw/, chapéu /ʃɐˈpɛw/ |
| oi | /oj/ | boi /boj/ |
| ou | /ow/ or /o/ | ouro /ˈowɾu/ or /ˈoɾu/ |
| ui | /uj/ | fui /fuj/ |
| iu | /iw/ | viu /viw/ |

### 7.3 ou の特殊処理

EP/BP ともに `ou` は単母音化して /o/ になるケースが多い:
- ouro → /ˈoɾu/（二重母音維持） or /ˈoɾu/（単母音化）
- outro → /ˈotɾu/（単母音化が一般的）

**実装方針**: デフォルトで /ow/ を出力し、異音規則（Phase 7 AllophoneProcessor）で /o/ への単母音化をオプション対応。

> **注**: 実用的な観点では、"ou" は多くの話者・方言で既に単母音 [o] に収束しており、デフォルトを /o/ とし保守的発音オプションとして /ow/ を提供する逆のアプローチも検討に値する。ただし ipa-dict のデータとの整合性を優先する場合は /ow/ デフォルトの現方針で問題ない。

### 7.4 三重母音

| パターン | IPA | 例 |
|---------|-----|-----|
| uai | /waj/ | Paraguai /paɾaˈgwaj/ |
| uei | /wej/ | averiguei /avɨɾiˈgwej/ |
| uou | /wow/ | aguentou /agwẽˈtow/ |

## 8. Phase 5: 母音弱化（非ストレス母音の還元）

### 8.1 ヨーロッパポルトガル語（EP）の母音弱化

EP は非常に強い母音弱化を持ち、ストレスのない母音は大幅に還元される:

| Phase 3 出力（ストレス母音） | 非ストレス時の弱化先（EP） | 例 |
|---------------------------|-------------------------|-----|
| /a/ | /ɐ/ | casa /ˈkazɐ/（語末 a → /ɐ/） |
| /ɛ/ | /ɨ/ (ほぼ無音) | Phase 3 で /ɛ/ に変換された母音も弱化対象 |
| /e/ | /ɨ/ (ほぼ無音) | pequeno /pɨˈkenu/ |
| /ɔ/ | /u/ | Phase 3 で /ɔ/ に変換された母音も弱化対象 |
| /o/ | /u/ | bonito /buˈnitu/ |

> **注**: Phase 3（母音変換）で既に /ɛ/ or /e/、/ɔ/ or /o/ に変換済みの音素が Phase 5 で弱化される。Phase 3 の出力が /ɛ/ だった場合と /e/ だった場合で Phase 5 の弱化先は同じ /ɨ/ であり、/ɔ/ と /o/ も同様に /u/ に弱化する。つまり非ストレス位置では開/閉の区別が中和される。

EP では非ストレスの e が /ɨ/ に弱化し、さらに完全に脱落することもある:
- despertar → [dʃpɨɾˈtaɾ]（e がほぼ無音）

### 8.2 ブラジルポルトガル語（BP）の母音弱化

BP の母音弱化は EP ほど極端ではない:

| ストレス母音 | 非ストレス語中（BP） | 非ストレス語末（BP） |
|------------|-------------------|-------------------|
| /a/ | /a/ | /ɐ/ |
| /ɛ/, /e/ | /e/ | /i/ |
| /ɔ/, /o/ | /o/ | /u/ |

### 8.3 実装方針

```
方言パラメータに基づく分岐:
  EP: 非ストレス a → /ɐ/, e/ɛ → /ɨ/, o/ɔ → /u/
  BP: 語末 a → /ɐ/, 語末 e → /i/, 語末 o → /u/
      語中は基本的に還元なし（/e/, /o/ を維持）
```

母音弱化は**ストレス位置が確定した後**に適用する必要があるため、Phase 5 とする。ストレス位置は Phase 1 の前に事前決定済み（セクション 6 冒頭の注記参照）。

## 9. Phase 6: 黙字処理

### 9.1 h の黙字

| パターン | 処理 | 例 |
|---------|------|-----|
| h（語頭） | 黙字（完全無音） | hora /ˈɔɾɐ/, homem /ˈɔmẽj̃/ |
| ch, lh, nh | ダイグラフ（Phase 1で処理済み） | |

ポルトガル語の h はフランス語と同様に語頭では完全に黙字。ダイグラフの一部としてのみ音価を持つ。

### 9.2 語末子音の処理

ポルトガル語はスペイン語と異なり、語末に来る子音の種類が限られる:

| 書記素 | EP | BP | 例 |
|--------|-----|-----|-----|
| -s | /ʃ/ | /s/ | mês |
| -z | /ʃ/ | /s/ or /z/ | vez |
| -r | /ɾ/ or 脱落 | /h/ or 脱落 | falar (coda r は方言で脱落傾向) |
| -l | /ɫ/ | /w/ | sol /sɔɫ/(EP), /sɔw/(BP) |
| -m | 鼻母音化（Phase 1） | 鼻母音化 | bom /bõ/ |
| -n | 鼻母音化（Phase 1） | 鼻母音化 | |

## 9bis. Phase 7: 異音処理（AllophoneProcessor）

Phase 7 は G2P ルールの後処理として `AllophoneProcessor` で異音規則を適用する。スペイン語/フランス語の `AllophoneProcessor` パターンに準拠し、方言パラメータで規則の有効/無効を制御する。

### 9bis.1 BP t/d 口蓋化

BP では t/d が /i/ の前で口蓋化する。母音弱化（Phase 5）の結果が入力となるため、Phase 5 の後に適用する必要がある:

| パターン | IPA (BP) | 例 |
|---------|----------|-----|
| t + i/ĩ | /tʃ/ | tia /ˈtʃia/, gente /ˈʒẽtʃi/ |
| d + i/ĩ | /dʒ/ | dia /ˈdʒia/, onde /ˈõdʒi/ |
| t + 語末e（弱化→i） | /tʃ/ | gente /ˈʒẽtʃi/（Phase 5 で e→i に弱化後に口蓋化） |
| d + 語末e（弱化→i） | /dʒ/ | verdade /veɾˈdadʒi/ |

### 9bis.2 EP b/d/g 弱化（lenition）

EP では有声破裂音 /b/, /d/, /g/ が母音間で摩擦音に弱化する（セクション 5.8 の規則詳細を参照）。

### 9bis.3 その他の異音規則

- **ou 単母音化**: /ow/ → /o/（オプション、セクション 7.3 参照）
- **coda r の脱落**: 方言によって語末 /ɾ/ が脱落（BP で顕著）
- **coda l の母音化**: BP で /l/ coda → /w/（セクション 5.7 の l を参照）

**処理フロー**: Phase 5（母音弱化）の出力 → AllophoneProcessor → 最終音素列

## 10. 特殊文字の処理

### 10.1 ç（セディーユ）

- 常に /s/
- a, o, u の前でのみ出現（e, i の前では c が直接 /s/ になるため不要）
- 例: coração /kuɾɐˈsɐ̃w̃/

### 10.2 ã / õ（チルダ）

- Phase 1（ダイグラフ + 鼻母音化）で処理
- ã → /ɐ̃/、õ → /õ/

### 10.3 アクセント記号（á, â, é, ê, í, ó, ô, ú）

- Phase 3（母音変換）で処理
- 急性アクセント（á, é, ó）→ 開母音
- 曲折アクセント（â, ê, ô）→ 閉母音
- í, ú → ストレス位置を示すのみ（音質は変わらない）
- à（アクセントグラーヴ）→ /a/（前置詞 a + 定冠詞 a の融合 "crase" を示す）。"à" は単語境界では独立トークンとして出現するため、テキスト正規化段階で通常の "a" として扱い、音素変換段階では特別な処理を必要としない

### 10.4 ü（トレマ）

- AO 1990（2009年発効）の正書法改定でポルトガル語から廃止
- 旧正書法テキストとの互換性のため、ü → u として処理
- güe/güi → /gwe/, /gwi/（改定後は gue/gui で u は発音する旨を文脈から判断）
- Phase 1（ダイグラフ認識）の gu 処理で、ü が存在する場合は u を黙字にせず /gw/ として処理する（セクション 3.4 参照）

## 11. 実装クラス構成（提案）

既存のスペイン語/フランス語パターンに合わせた構成:

```
DotNetG2P.Portuguese/
├── Rules/
│   ├── GraphemeToPhonemeRules.cs    # メイン G2P ルール（7フェーズ統合走査）
│   ├── PortugueseOrthography.cs     # 正書法ヘルパー（母音/子音判定等）
│   ├── NasalVowelizer.cs            # 鼻母音化ロジック（Phase 1 に統合）
│   ├── PortugueseSyllabifier.cs     # 音節分割（書記素レベル、前処理）
│   ├── StressAssigner.cs            # ストレス位置決定（前処理）
│   ├── VowelReducer.cs              # 母音弱化（Phase 5、方言依存）
│   └── AllophoneProcessor.cs        # 異音規則・Phase 7（BP t/d口蓋化、EP b/d/g弱化、l暗音化/母音化、ou単母音化等）
```

### 11.1 GraphemeToPhonemeRules.cs の処理フロー

```csharp
public static PortuguesePronunciation ConvertWord(string word, PortugueseDialect dialect, bool enableExceptionDictionary = true)
{
    // 0. 例外辞書チェック
    if (enableExceptionDictionary && ExceptionDictionary.TryLookup(word, dialect, out var exception))
        return exception;

    // 1. 書記素レベルの音節分割 + ストレス位置決定（前処理）
    //    ストレス位置は Phase 3（母音変換）と Phase 5（母音弱化）で必要
    var syllables = PortugueseSyllabifier.Syllabify(word);
    var stressedSyllables = StressAssigner.MarkStress(word, syllables);

    // 2. 各音節を音素に変換（Phase 1-4 統合走査）
    //    Phase 1: ダイグラフ + 鼻母音化（NasalVowelizer 統合）
    //    Phase 2: 文脈依存子音
    //    Phase 3: 母音変換（ストレス依存）
    //    Phase 4: 半母音化
    var phonemes = ConvertGraphemes(word, stressedSyllables, dialect);

    // 3. 母音弱化適用（Phase 5）
    VowelReducer.Apply(phonemes, stressedSyllables, dialect);

    // 4. 黙字処理（Phase 6）
    RemoveSilentLetters(phonemes);

    // 5. 異音処理（Phase 7 — AllophoneProcessor）
    //    BP: t/d 口蓋化（母音弱化後に適用）
    //    EP: b/d/g 弱化
    //    共通: ou 単母音化（オプション）等
    AllophoneProcessor.Apply(phonemes, dialect);

    // 6. 音節オフセット・ストレス情報を構築
    return BuildPronunciation(phonemes, stressedSyllables);
}
```

## 12. 例外辞書の必要性

ポルトガル語はスペイン語よりも例外辞書への依存度が高い:

### 12.1 例外辞書が必要なケース

1. **無標ストレス e/o の開閉**: 正書法だけでは決定不可能
   - belo /ˈbɛlu/ vs. pelo /ˈpelu/
2. **x の発音**: 4通りの発音が正書法だけでは決定不可能
   - exame /iˈzɐmi/ vs. fixo /ˈfiksu/ vs. xadrez /ʃɐˈdɾeʃ/
3. **外来語**: 通常のルールが適用されない
   - show /ʃow/, pizza /ˈpitsɐ/

### 12.2 推定エントリ数

- スペイン語: 比較的少数（50-100エントリ程度）
- フランス語: 500+エントリ
- ポルトガル語: **300-800エントリ**（推定）。x の不規則性と e/o の開閉が主要因。

> **注**: metaphony（形態素レベルの母音交替、例: avó/avô, novo/nova）を例外辞書で網羅的に扱う場合は上限の 800 を超える可能性がある。ポルトガル語 G2P 研究論文では約 228 語の e/o 同音異義語ペアが報告されており（Springer "Generating a pronunciation dictionary for European Portuguese"）、これらを含めると見積もりの上限に近づく。

## 13. まとめ: スペイン語/フランス語との比較

| 特徴 | スペイン語 | フランス語 | ポルトガル語 |
|------|----------|----------|------------|
| フェーズ数 | 3 | 6 | 7（提案、概念的分割。実装は統合走査） |
| 母音体系 | 5母音（単純） | 12口母音+4鼻母音 | 7口母音+5鼻母音（+弱化形） |
| 鼻母音 | なし | あり（4つ） | あり（5つ + 鼻二重母音5つ） |
| 母音弱化 | なし | schwa処理 | 大規模弱化（特にEP） |
| 子音の位置依存 | 少ない | 中程度 | 大きい（s/z, r, l, x） |
| 方言差の影響 | 小（seseo/distincion） | 小（un の発音） | 大（EP/BP で音韻体系が異なる） |
| 異音規則 | b/d/g弱化 | R無声化、有声性同化 | EP b/d/g弱化 + BP t/d口蓋化 + coda s方言差 |
| 例外辞書依存度 | 低い | 中〜高（500+） | 中〜高（300-800推定、metaphony含むと800超の可能性） |
| 黙字 | ほぼなし | 多い | 少ない（h のみ）。AO 1990 で旧正書法の黙字子音（cc等）を廃止 |
| 最も不規則な文字 | なし | e（位置の法則） | x（4通り）、e/o（開閉） |
